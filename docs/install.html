Fifteen Minutes to Your Studio

Everything needed to go from a bare Mac to typing /cmo:new in your own Claude Code. Most of the time is spent waiting for installs; none of it requires knowing anything about video, audio, or plugins.

Step 01

Install the Tools

The studio leans on a few ordinary tools. One command installs them.

You need a Mac with Claude Code already working. Then, in Terminal:

brew install node uv ffmpeg

If you plan to make films from screen recordings, also install Apple's command line tools — the studio uses them to read the text inside your footage:

xcode-select --install
If something complains later
A message about the Swift compiler and SDK being "out of step" means your command line tools are older than your system. Open Software Update, install the newest "Command Line Tools for Xcode" it offers, and the complaint goes away.
Step 02

Get the Studio Folder

Clone the repository, or copy the folder from a colleague. Where you put it doesn't matter.

git clone https://github.com/vobbilis/tme-agents.git ~/tme-agents

The rest of this page assumes it lives at ~/tme-agents.

Step 03

Add the Fonts

The films use HPE's brand typeface. It is licensed for internal use, so the font files are not in the repository — you copy them in once.

Follow the short instructions in packs/PROVISIONING.md inside the folder: four font files, copied into three places, taken from any colleague's working install. The studio verifies the fonts before building anything, so a mistake here is caught and explained in plain words rather than discovered in a finished film.

Step 04

Tell Claude Code About It

Pick one of two ways. The simple one suits almost everyone.

  1. Simple
    Load it in every session.

    Link the folder into Claude Code's skills directory: mkdir -p ~/.claude/skills && ln -s ~/tme-agents ~/.claude/skills/cmo — the studio stays quietly out of the way when you aren't making a film.

  2. Cautious
    Load it only when you ask.

    Start Claude Code with claude --plugin-dir ~/tme-agents whenever you want the studio available.

Step 05

Check It Worked

One command tells you everything.

Start a new Claude Code session and type:

/cmo:new help

You should see a usage page describing the three kinds of film and the four-person review team. If Claude says it doesn't know that command, the plugin didn't load — the usual cause is a typo in the path from step 04.

Two things worth knowing
Everything you record and provide stays on your computer; the one exception is the narration text, sent to Microsoft's voice service only after you approve it in so many words. And the first time a film checks its own narration, a small speech-recognition model downloads once — your audio never leaves the machine for that check.
Step 06

Make Your First Film

Make a folder for the film, open Terminal there, start Claude Code, and type /cmo:new. From that point the studio carries you.

The full walkthrough of what making a film feels like — what you bring, the four things you'll ever be asked to do, and what the studio refuses to do — is on the overview page, with the complete written version in HOWTO.md.
